# Zalith Launcher — community landing page

Trang giới thiệu tĩnh, viết bằng HTML/CSS/JavaScript thuần, phù hợp GitHub Pages.

## Xem thử
Mở `index.html` bằng trình duyệt.

## Đăng lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Tải lên `index.html`, `style.css`, `script.js` và `README.md` (hoặc giải nén ZIP rồi tải cả bốn file lên).
3. Vào **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/(root)`, rồi Save.
5. Đợi GitHub xuất bản trang và mở URL Pages được cung cấp.

## Trước khi xuất bản
Trong `index.html`, thay liên kết `https://github.com/` ở nút GitHub bằng URL kho phát hành chính thức của Zalith Launcher nếu bạn đã xác minh đúng URL.

Đây là mẫu giao diện cộng đồng không chính thức, không phải website chính thức của Zalith Launcher. Không bao gồm tệp cài đặt APK.
